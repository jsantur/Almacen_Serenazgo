## 📌 Acerca del Proyecto

**Almacén Pro** es una aplicación web desarrollada para facilitar la administración, control y seguimiento de los productos y materiales almacenados.

El sistema permite gestionar productos, registrar movimientos de **entrada, salida y ajuste**, consultar el **Kardex**, controlar existencias y visualizar información relevante del inventario desde una interfaz web moderna y adaptable.

La plataforma está orientada especialmente a la gestión de **vestuario, equipamiento, equipos de protección personal (EPP), materiales de limpieza, útiles de oficina, suministros y otros recursos de almacén**.

Su objetivo principal es proporcionar una herramienta centralizada que permita mantener un mayor control sobre las existencias, movimientos y distribución de materiales.

## 🎯 Objetivos

* Mejorar el control general del inventario.
* Registrar de manera organizada las entradas y salidas de productos.
* Mantener actualizado el stock disponible.
* Facilitar la consulta rápida de productos.
* Llevar un historial detallado mediante Kardex.
* Registrar a las personas que reciben materiales.
* Organizar los productos por categorías y familias.
* Diferenciar productos inventariables y consumibles.
* Facilitar la identificación de productos y variantes.
* Reducir errores durante los procesos de almacén.
* Generar información útil para la toma de decisiones.
* Permitir el acceso desde computadoras, tablets y dispositivos móviles.

## 📍 Control de Ubicación

Almacén Pro permite organizar físicamente los productos dentro del almacén mediante información de ubicación.

Ejemplo:

```text
Almacén
│
├── Pasillo
│   ├── Estante
│   │   ├── Nivel
│   │   │   └── Caja
│   │
│   └── Zona
│
└── Ubicación del producto
```

Esto facilita la localización física de los materiales y permite conocer dónde se encuentra cada producto dentro del almacén.
